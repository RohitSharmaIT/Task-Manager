# 📝 Task Manager – MERN Stack

A simple **Task Management System** built using the **MERN stack** as part of an assignment submission.

📄 **GitHub Repository Link:**  
[Check Here](https://github.com/RohitSharmaIT/Task-Manager.git)

📄 **Task Requirements (PDF):**  
[View PDF](https://drive.google.com/file/d/1hUEACDSdACrVV73hB2WXoUqH1bgB2ZMj/view?usp=sharing)

---

## 🚀 Features
- User Authentication
- Create, Edit, View & Delete Tasks
- Task Status (Pending / Completed)
- Priority-based Task Lists (Color Coded)
- Confirmation before Deletion

---

## 🛠 Tech Stack
- **Frontend:** JavaScript, TypeScript, React  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  

---

## ⚙️ Run Locally

### Front-End
```bash
cd Front-End
npm install
npm run dev
```
### Back-End
```bash
cd Back-End
npm install
npm run start
```
